# MirraFit

MirraFit is a native Android app that helps you log your strength training in a simple and clear way.

## Features

- **Training plan:** Create and edit exercises with sets and reps
- **Live workout:** Timer, set progress and volume during your session
- **History:** All saved sessions grouped by week and month
- **Personal records:** New bests are detected automatically and highlighted
- **Weekly goal & streak:** Keep track of how consistent you are
- **Last performance:** See what you achieved last time for each exercise

## Tech stack

- Kotlin
- Jetpack Compose (Material 3)
- Local data storage on the device
